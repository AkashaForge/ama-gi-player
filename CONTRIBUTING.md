# Contributing to Amagi-Player

Спасибо за интерес к проекту! Ниже — краткие правила для тех,
кто хочет помочь.

---

## Как контрибьютить

1. **Fork** репозитория.
2. Создайте ветку от `main`: `git checkout -b feature/my-feature`
3. Внесите изменения.
4. Убедитесь, что приложение запускается: `python main.py`
5. Откройте **Pull Request** в `main`.

---

## Стиль кода

- Python 3.10+, PEP 8.
- Типизация приветствуется, но не обязательна.
- Не добавляйте зависимости без обсуждения в Issue.
- Не рефакторите чужой код «попутно» — отдельный PR на
  отдельную задачу.
- Публичные функции и классы сопровождайте docstring.

---

## Лицензия вклада

Отправляя PR, вы соглашаетесь лицензировать свой вклад под
**GNU GPL v3.0**.
