# Security Policy

## Supported versions

Only the latest release is supported with security updates.

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report security issues privately to the maintainer via GitHub's
"Report a vulnerability" feature on the repository's Security tab:

https://github.com/AkashaForge/ama-gi-player/security/advisories/new

Please include:

- A description of the issue and its potential impact
- Steps to reproduce (or a proof-of-concept)
- The affected version(s)

You will receive an acknowledgment within 72 hours. Please allow
reasonable time for a fix before public disclosure.
